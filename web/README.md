# Recruiting Copilot — web

Next.js 16 frontend for the Recruiting Copilot API: paste or pick a job posting, use the
sample resumes or upload your own (PDF/TXT, up to 10), and get a ranked shortlist with
reasons, review suggestions and bias flags.

## Run locally

```bash
npm install
npm run dev          # http://localhost:3000
```

By default it calls the deployed API. To use a local API (`uvicorn app.main:app` in the repo
root), create `web/.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## Deploy (Vercel)

Import the repository in Vercel and set **Root Directory** to `web`. Optionally set
`NEXT_PUBLIC_API_URL`. The API allows CORS from `https://recruiting-copilot*.vercel.app`;
for another domain, add it to the API's `CORS_ORIGINS` environment variable.

## Layout

- `src/app/page.tsx`: page shell and "how it works"
- `src/components/Screener.tsx`: inputs and request state
- `src/components/ResultView.tsx`, `CandidateCard.tsx`: bias flags, job summary, ranking
- `src/lib/api.ts`: typed API client (types mirror `app/domains/recruiting/schemas.py`)
- `src/lib/samples.json`: generated by `python -m scripts.export_samples` from the eval data
